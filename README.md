# 정벌 던전의 다캐릭터 활용 설계

던전앤파이터 모바일 정벌 던전 ‘삭룡 갈리아르’의 콘텐츠 역기획서.

- 최초 모험단 월드보스 기획에서 정벌 던전으로 변경된 배경
- 3캐릭터 APC 편성 및 로테이션 시스템
- 직관적인 전투와 캐릭터별 기여도
- 피로도 보전, 장비 성장과 참여 동기

자료 기준: 2026년 11월 24일.

근거: [10/8 개발자 노트](https://dnfm.nexon.com/News/Devnote/View/3559883), [10/13 개발자 노트](https://dnfm.nexon.com/News/Devnote/View/3562500).
